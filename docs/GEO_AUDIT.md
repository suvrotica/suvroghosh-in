# GEO Audit — suvroghosh.in

Technical audit of conventional-search and generative-search discoverability. The original review
was performed against a production build (`npm run build`) served locally with `npm run preview`.
The provider-specific research and crawler policy were refreshed on 2026-07-22. Evidence comes from
official provider documentation and the final server-rendered HTML of representative routes, not
only Svelte source.

Audit dates: 2026-07-18; provider refresh 2026-07-22.

## Provider-specific crawler and retrieval findings

The key distinction is between **search/citation indexing**, **user-directed retrieval**, and
**possible future model training**. These are separate systems. Allowing a training crawler does
not guarantee dataset inclusion, model influence, memory, attribution, or a citation. For this site,
live search citation is the nearer and measurable objective.

| Product           | Search or retrieval route                                                                                | Training route                                    | Evidence-backed site action                                                                                           |
| ----------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| ChatGPT           | `OAI-SearchBot`; user fetch via `ChatGPT-User`; OpenAI also names Bing as a search provider              | `GPTBot`                                          | Allow the official search bot, keep Bing indexed/fresh, and track `utm_source=chatgpt.com` referrals                  |
| Claude            | `Claude-SearchBot`; user fetch via `Claude-User`                                                         | `ClaudeBot`                                       | Allow the search/retrieval agents; Anthropic documents no separate publisher submission portal                        |
| Perplexity        | `PerplexityBot`; user fetch via `Perplexity-User`; unnamed third-party crawlers may supplement its index | None documented for foundation-model training     | Allow the bot and verify real bot traffic against current published IP ranges                                         |
| Kimi              | `Kimi-SearchBot`; user fetch via `Kimi-User`                                                             | `KimiBot`                                         | Allow the search and user agents; Kimi publishes distinct user agents and IP lists                                    |
| Baidu / ERNIE     | Baidu Search index via `Baiduspider`                                                                     | Not established by the reviewed webmaster sources | Verify the site and submit the sitemap in Baidu Search Resource Platform                                              |
| Qwen / Alibaba    | Qwen supports live web search; Quark is a named Alibaba search route; Shenma uses `yisouspider`          | Not established                                   | Submit to Shenma as the best documented Alibaba-family discovery route, without claiming it guarantees Qwen inclusion |
| Yuanbao / Tencent | Tencent says Yuanbao uses Tencent Web Search API, which is derived from Sogou Search                     | Not established                                   | Allow Sogou crawlers and submit the sitemap in Sogou Webmaster                                                        |
| DeepSeek          | Official products have Internet Search                                                                   | No public source inventory usable by publishers   | There is no documented DeepSeek crawler, index provider, or submission channel; do not invent a `DeepSeekBot` rule    |

The explicit `robots.txt` rules match the owner's stated wish to participate in both live discovery
and the open corpus: search agents, user fetchers, `GPTBot`, `ClaudeBot`, `KimiBot`, and `CCBot` are
allowed. The wildcard rule already made the site permissive; the explicit groups clarify intent and
let the validator catch future accidental blocking. This is eligibility, not a licence declaration
or a promise of inclusion. Training access can later be reversed independently without sacrificing
OpenAI, Anthropic, or Kimi search access.

`CCBot` is explicitly allowed because Common Crawl supplies an open research corpus and reads the
sitemap announced in `robots.txt`. Common Crawl describes its dataset as a sample of the web rather
than a complete archive, so access and sitemap discovery still do not guarantee capture.

None of the OpenAI, Anthropic, Perplexity, Kimi, Baidu, Alibaba, Tencent, Sogou, or Shenma sources
reviewed describes publisher-hosted `llms.txt` as a ranking or ingestion signal. Its use here is a
curated signpost for agents that choose to read it, not a substitute for ordinary crawlability.

## Summary

The site's technical foundation is stronger than the original concern suggested: full SSR article
text, canonical redirects, per-article social metadata, coherent entity-linked JSON-LD, a complete
sitemap, RSS autodiscovery, deep internal links, and permissive crawler access are in place. Live
production checks on 2026-07-22 returned `200` for representative pages to the named AI user agents;
the sitemap exposed 654 canonical URLs and the RSS feed exposed 25 recent items.

The site is therefore facing more of a **selection and authority problem than a crawlability
problem**. A broad web search found indexed pages but did not place the site above established
institutional sources for generic HIE queries. The next gains will come from making selected pages
uniquely useful primary sources: explicit claims, evidence and outbound citations, stable identity,
truthful update dates, external corroboration/backlinks, and selective bilingual summaries where a
Chinese-language audience is genuinely relevant. Mass FAQs, keyword repetition, schema inflation,
or 530 near-identical “AI summaries” would add noise rather than authority.
