# Bing Webmaster Tools

## Access verdict

**UNVERIFIED — REQUIRES OWNER ACTION.**

The Bing Webmaster Tools browser opened to its signed-out public entry page; no authenticated site property or account report was available. The audit did not sign in, import from Google Search Console, add or verify a site, submit a sitemap, run Site Scan, or change crawl/index settings.

A separate public Bing search attempt was stopped by Bing's automated challenge before result evidence was available. No challenge was bypassed. Therefore Bing indexing, search performance, crawl errors, sitemap state, backlinks, malware/security status, and URL inspection are all unverified.

Official Bing documentation says Search Performance can expose clicks, impressions, CTR, average position, crawl requests/errors, indexed pages, page/query details, and CSV exports for up to six months. None of those values is assumed here.

Official references: [Bing Search Performance](https://www.bing.com/webmasters/help/search-performance-c680da36), [add and verify a site](https://www.bing.com/webmasters/help/add-and-verify-site-12184f8b), and [user roles](https://www2.bing.com/webmasters/help/how-to-add-users-to-your-site-account-d5d00364).
