# How fingerprints form

The [visualization](/blog/visualizations/how-fingerprints-form) solves the saturated Gierer–Meinhardt system used by [Glover and colleagues (2023)](https://doi.org/10.1016/j.cell.2023.01.015). Its geometry, initiation profiles and boundary schedule follow the human model in the [authors’ mathematical appendix, equations 8–13 and Figure Ax2](https://github.com/AndrewLKrause/fingerprint-simulations/blob/main/Model%20Details.pdf). We reviewed the geometry and original model coordinate convention and wrote the solver independently; the site does not distribute the authors’ COMSOL model, figures or code. [Turing (1952)](https://doi.org/10.1098/rstb.1952.0012) supplies the general instability principle; [Li and colleagues (2022)](https://doi.org/10.1016/j.cell.2021.12.008) document inherited influences on fingerprint patterns.

## Model and display

The surface is a hemicylinder of length 600 and reference radius 240, joined to a spherical quadrant at its equator. The grid uses angular and meridional coordinates, with cell centres on the curved surface. The finite-volume flux uses physical cell areas, distances and face lengths; circumferential cells contract towards the cap tip. The model does not diffuse on a flat bitmap. The positive equilibrium is approximately `(u, v) = (9.4663, 16.2928)`. The initial activator bump is absent for Arch, curved and extended for Loop, and localised on the pad for Whorl. Inhibitor starts at equilibrium.

The boundary begins with zero normal derivative for both signals. On active faces the activator obeys `(1 − A) ∂ₙu + Au = 0`; `A` increases linearly from zero to one during the 100 model units after the chosen onset. At `A = 1` the face has zero activator. The finite-volume discretization eliminates the face value to obtain the corresponding outward loss. Inhibitor retains zero normal derivative. Nail activation covers the cap meridians only for Arch; it also covers the upper half of the cylinder’s two side edges for Loop and Whorl. Crease activation applies along the basal edge. The reference nail/crease onsets are 100/0 for Arch and 50/50 for Loop and Whorl.

The solver advances a fixed model step, using a first-order implicit–explicit update with Douglas alternating-direction diffusion and implicit linear decay. Time-dependent boundary coefficients are evaluated at step midpoints. It checks both signal arrays for invalid values and stops rather than repeatedly clipping them. The browser runs the same solver used for the fixtures, as a separate module worker. It transfers only activator snapshots and uses the current run ID to reject obsolete results.

Print and Signal interpolate the same activator field. The Print curve maps activator `u = 9.75…14.4` from paper to ink, with a smooth transition. The Signal scale is fixed at `0…22`. The view is a flat angular map: horizontal angle spans each latitude’s width, vertical position follows axial height, and the base bends slightly in the display. The compressed tip uses extra vertical samples to reduce aliasing. There is no imposed ridge orientation, bitmap texture or calibrated contact-pressure model.

## Reproduction and limits

The [asset record](../../static/images/visualizations/how-fingerprints-form/assets.json) lists the exact preset/seed records, mesh and time settings, end-frame hashes, and the sources used to generate the examples. [Nine completed fields](../../artifacts/fingerprints/family-variations.png) and [formation frames](../../artifacts/fingerprints/formation.png) come from the numerical solution. The saved Loop field provides the first still, including the Signal view and export before the first live run. Each live run stops at model time 1000. That is a display endpoint, not a convergence-to-steady-state test or a biological clock. The source paper also shows fields at time 2500. Reader settings are teaching-scale values, and modified presets may produce intermediate arrangements.

| Control                   | Tested interval and mapping                                                                                                                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Ridge spacing             | `0.92×…1.12×`; both diffusion coefficients multiply by the square of this value, with the domain and kinetics fixed.                                                                                                     |
| Starting position         | `−0.15…+0.15` radians added to the pad profile; unavailable for Arch.                                                                                                                                                    |
| Wave timing               | `−24…+24` model units relative to the preset’s crease onset; Arch starts at zero and can only move later. Nail timing stays fixed.                                                                                       |
| Fingertip width           | `0.94×…1.08×` radius; the cap and cylinder are both recomputed at fixed axial cylinder length.                                                                                                                           |
| Small initial differences | `0…0.02` fractional activator perturbation (default `0.012`) from a seeded smooth field with lattice spacing 24 model units. Perturbation is restricted to the pad bump or, for Arch, the region adjacent to the crease. |
| Variation number          | Unsigned 32-bit integer. Same backend, settings and seed reproduce the same run; different runtimes can round arithmetic differently.                                                                                    |

The standard mesh uses 377 columns and 488 rows at the reference width, with maximum cell spacing near 2 model units and a time step of 0.5. The homogeneous reaction Jacobian has trace −5.16594 and determinant 2.56179. Diffusion destabilises a band of eigenvalues of `−ΔS` from 0.05796 to 0.24555, with a fastest continuous wavelength near 17.74 model units (about 8.2 cells at the closest setting). In the actual Neumann surface discretization, a measured mode with eigenvalue 0.124711 grows by about 2.2% per step; the uniform mode decays. The no-diffusion homogeneous control does not form ridges.

In the lower Loop crease front, median crest distance was 16.97, 18.44 and 20.71 model units at `0.92×`, `1.00×` and `1.12×`. At reference spacing it was 18.28 after halving the time step, and 18.55 after refining the mesh by 25%. At time 600 the area-weighted field error fell from 1.885 to 1.068 between successive time refinements and from 1.052 to 0.506 between successive mesh refinements. Individual ridge endings can still move. Ten single-control Loop endpoint runs plus two combined endpoint runs for each family remained finite and positive through the end time. The [calibration receipt](../../artifacts/fingerprints/calibration.json) records the settings, extrema and comparisons. The implementation keeps this numerical quality fixed across devices; slower devices may take longer to finish.

On Windows with an Intel Core i5-12500H and headless Chrome, an explicit Loop replay on the production preview reached time 450 in 6.02 seconds and finished in 13.53 seconds. A run in the isolated preview under concurrent build load took 10.76 and 23.87 seconds respectively. The saved Loop is available before computation. The instrument shows simulation time while a fresh run forms.

Primary text on the panel measures 12.7:1 contrast, secondary text on raised controls 6.75:1, dark text on the amber button 7.45:1, and the focus outline against the panel 8.83:1. The feature was reviewed at desktop and 375 px widths.

Use `npm run fingerprint:assets` to regenerate the example images, field, contact sheets and manifest. `npm run fingerprint:assets:check` checks the image pixels, raw frame and source hashes without running another simulation. `npm run fingerprint:calibrate --silent` regenerates the numerical receipt. `npm run fingerprint:test` and `npm run fingerprint:check` run the focused numerical and type checks. `npm run fingerprint:browser:test` runs the browser checks against a loopback production preview (or the URL in `FINGERPRINT_BASE_URL`).

The site serves `/images/` with immutable caching. If a future release changes the example pixels or default field after publication, give the changed assets new URLs and update the article, preset preview references and default field loader together.
